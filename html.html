Lecture 2: HTML Basics

Core elements, syntax, text formatting, and lists

Summary

Covers standard HTML document structure, essential content tags, headings, formatting tags, and ordered/unordered lists.

Topics Covered:
  • HTML Document Skeleton
    • Document Setup
      • <!DOCTYPE html> declaration
      • <html>, <head>, <body> tags
    • Text Elements
      • Headings (<h1> to <h6>)
      • Paragraphs & breaks (<p>, <br>)
      • Formatting (<strong>, <em>)
    • List Structures
      • Unordered lists (<ul>)
      • Ordered lists (<ol>)
Example Code:
<h2>HTML Basics</h2> <p>Learning <strong>HTML</strong> is easy.</p> <ul> <li>Headings &amp; Paragraphs</li> <li>Lists &amp; Formatting</li> </ul>

HTML Basics

Learning HTML is easy.

  • Headings & Paragraphs
  • Lists & Formatting
