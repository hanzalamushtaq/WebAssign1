Lecture 7

Lecture 7: Responsive Web Design

Mobile-first design, fluid units, and media queries

Summary

Covers crafting responsive websites adaptable across smartphones, tablets, laptops, and desktops using Media Queries and fluid units.

Topics Covered:
  • Responsive Development
    • Viewport Setup
      • <meta name="viewport">
      • Device-width & initial scale
    • CSS Media Queries
      • @media screen rules
      • Breakpoints (mobile/desktop)
    • Fluid Units
      • Percentages (%)
      • Viewport units (vw, vh)
      • Flex layout wrapping
Example Code:
<style> @media (max-width: 600px) { .resp-badge { color: red; } } </style> <span class="resp-badge">Fluid Element</span>
